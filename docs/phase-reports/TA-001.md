## API geçişi ve veri

- `POST /vision/analyze` geçerli analiz için sunucu kimliği döndürür. `POST /lessons/generate` gövdesinde `{"analysis_id":"…"}` kullanılır. Saklanan kaynakta görsel önizlemesi ve hata ayıklama alanları bulunmaz.
- `POST /lessons/{id}/interact` için eylem ile isteğe bağlı ipucu düzeyi yeterlidir. Sunucu öğrenci ve ders sahipliğini denetler. Başka öğrenci ve bilinmeyen kaynak 404 döndürür.
- `POST /students/me/lessons` eski istemciler için mevcut yetkili kaydı döndürür. Paylaşım ve geri bildirim `lesson_id` kabul eder. Eski `analysis`, `lesson` ve `result` gövdeleri desteklenir. Önceki sürümde üretilmiş ve güvenilir kaynak kaydı bulunmayan dersler yeniden çözülmelidir.
- Yeni derslerin geçmişi mevcut `lessons` koleksiyonundadır. İç JSON, Firestore’un iç içe dizi kısıtına takılmadan grafik noktalarını korur. Eski `lesson_data` alanı okunabilir. Geçmiş ekranı eski kayıtların doğrulama kaynağını belirtir.
- Yeni paylaşım genel bir başlık, işlem adımları ve matematiksel sonuç içerir. Kaynak fotoğrafı, ham soru metni, serbest anlatım ve öğrenci profili dışarı aktarılmaz. Güvenli biçimde gösterilebilen sonuç yoksa 422 döner. Önceden yayımlanan bağlantılar mevcut içerikleriyle açılır. Eski paylaşımlar için geriye dönük bir gizlilik temizliği uygulanmadı.
- Pratik yanıtında dersin sahibi kontrol edilir. Soru bir saat geçerlidir. İlk doğru yanıt veya üç farklı deneme soruyu kapatır. Aynı yanıtın tekrarı saklanan geri bildirimi döndürür. Pratik kabulü ardından istatistik yazımı kesilirse aynı yanıtla tekrar denemek aynı olay kimliğiyle yazımı tamamlar.
- Genel sağlık, sürüm, sağlayıcı yapılandırma özeti ve yayımlanmış çözüm görüntüleme açık kalır. Firebase oturumu gerekli yollarda 401, geçerli kimliğin yetmediği durumda 403 döner.
- Çalışan HTTP şemasına `/openapi.json` üzerinden erişilir. TypeScript v1 tipleri hâlen elle tutuluyor. Sonraki uyumsuz değişiklik, ayrı sözleşme sürümü ve üretilen tiplerle bir geçiş gerektirir.

## Maliyet ve gözlemlenebilirlik

`.env.example` ayarların tam listesini içerir. Günlük toplam ücretli işlem sınırı 50’dir. İşlem başına varsayılanlar analiz 20, ders 20 ve etkileşim 40’tır. Önizleme, pratik yanıtı, geri bildirim ve yerel “Anladım” eyleminin ayrıca sayaçları vardır. Kabul edilen deneme, sağlayıcı hata verse de işlem kotasından düşer. Çıktı çağrı başına en fazla 4.096, kullanıcı ve UTC günü başına 100.000 token olarak ayarlıdır. Her sağlayıcı çağrısından önce azami çıktı miktarı ayrılır. Bildirilen gerçekleşen çıktıya göre kullanılmayan kısım geri verilir. Belirsiz tüketimde rezervasyon korunur.

- `TEACHERAI_AI_ENABLED=false` ücretli yolları kapatır. `TEACHERAI_AI_CONCURRENCY` süreç başına eşzamanlı yazma/yükleme sayısını sınırlar. Firestore kotaları süreçler arasında ortaktır. Herkesi kapsayan USD harcama tavanı uygulanmaz.
- `Idempotency-Key` aynı kullanıcı, işlem ve UTC günü içinde tekrar gönderilirse 409 döner. Bu, tekrar ücretlendirmeyi engelleyen kabul kaydıdır. Önceki HTTP cevabını önbellekten döndürmez. Üretilen başarılı ders geçmişten görülebilir.
- JSON sınırı 750.000 bayt, dosya sınırı 10 MiB, aktarım süresi 60 saniyedir. SDK iç tekrarları kapalıdır. Bağlamı küçültme ve matematiksel düzeltme uygulama düzeyinde sınırlıdır.
- Cloud Run’a uygun JSON kullanım kaydı istek kimliği, işlem, sağlayıcı, yanıt modeli, mevcutsa sağlayıcı istek kimliği, giriş/çıktı/toplam, önbellek ve akıl yürütme tokenları, süre, tekrar sayısı ve durumu içerir. Eksik ölçümler bilinmeyen olarak kalır. Ham görsel, sohbet, prompt ve kimlik jetonları bu kayda konmaz.
- Tahmini USD için `TEACHERAI_PRICING_VERSION` ve `TEACHERAI_MODEL_PRICES` birlikte yapılandırılır. JSON anahtarı yanıtta dönen modeldir. Değeri milyon token başına sırasıyla normal giriş, önbellek girişi ve çıktı USD oranlarıdır. Bu basit hesap standart tarife içindir. Farklı bölge, hizmet sınıfı veya özel tarife için doğrulanmış fiyat yoksa ilgili modeli tanımlamayın.

## Firebase ve App Check geçişi

1. Mevcut web uygulamasının Firebase proje ayarlarından API anahtarı, Auth domain, project ID ve app ID alınır. Dört `NEXT_PUBLIC_FIREBASE_*` değeri statik web derlemesine verilir. Mevcut e-posta/parola oturum yöntemi ve Hosting alan adları ilgili Auth projesinde doğrulanır.
2. `TEACHERAI_FIREBASE_PROJECT_ID` mevcut Firestore projesini seçer. Web kimliği ayrı projedeyse `TEACHERAI_FIREBASE_AUTH_PROJECT_ID` web kaydının gerçek project ID değerine ayarlanır. Cloud Run hizmet hesabının Firestore okuma/yazma ve Auth kullanıcı durumunu okuma yetkileri doğrulanır. Geçmiş sorgusu için gerektiğinde mevcut `lessons` koleksiyonunda `student_id ASC, created_at DESC` bileşik indeksi doğrulanır. Hiçbir canlı yetki veya indeks bu fazda değiştirilmedi.
3. Web uygulamasının Auth/App Check projesinde izin verilen Hosting ve özel alan adlarıyla puan tabanlı reCAPTCHA Enterprise site anahtarı hazırlanır. Firebase Console → App Check → Apps altında mevcut web kaydı seçilir, reCAPTCHA Enterprise sağlayıcısı ve site anahtarı kaydedilir. Hizmetin kotası ve olası maliyeti işletmeci tarafından gözden geçirilir. [Firebase web kurulumu](https://firebase.google.com/docs/app-check/web/recaptcha-enterprise-provider)
4. Web derlemesine `NEXT_PUBLIC_FIREBASE_APP_CHECK_SITE_KEY` verilir. API önce `TEACHERAI_APP_CHECK_MODE=monitor` ile çalıştırılır. Geçerli, eksik ve geçersiz belirteçli istekler test ortamında karşılaştırılır. Kapsama doğrulanınca `enforce` seçilir. Sorun durumunda `monitor` aşamasına dönülür. Bu özel API için uygulama kapısı Cloud Run ayarıdır. Varsayılan `off`; canlı etkinlik doğrulanmadı. [İstemci başlığı](https://firebase.google.com/docs/app-check/web/custom-resource) · [Sunucu doğrulaması](https://firebase.google.com/docs/app-check/custom-resource-backend)

## Model yaşam döngüsü

Aktif Python varsayılanları, Compose ve ortam örneği Vision/Interaction için `gpt-4.1-mini`, Lesson için `gpt-5.6-terra` seçer. Üçü de Responses ve yapılandırılmış çıktı kullanır. Vision ayrıca görüntü girdisi gerektirir. OpenAI belgelerinde GPT-4.1 mini snapshot’ı için kapanış **14 Ocak 2027**, önerilen geçiş **gpt-6-luna** olarak yayımlanmıştır. Adayın model kartı görüntü girdisi, Responses ve Structured Outputs desteğini gösterir. Hesap erişimi ve Türkçe eğitim kalitesi ayrıca sınanmalıdır. [OpenAI kapanış tablosu](https://developers.openai.com/api/docs/deprecations) · [Aday model kartı](https://developers.openai.com/api/docs/models/gpt-6-luna)

Depo kökünde çevrimdışı komut `python -m scripts.evaluate_models` iki sentetik fikstürün oluşturulmasını denetler. Bütçe ve değerlendirme anahtarı yetkilendirildiğinde aşağıdaki komut aynı örnekleri her işlemde önce mevcut, sonra aday modele gönderir. Standart çıktı sonuç satırlarını, standart hata kullanım kayıtlarını taşır. Tek ve çift köklü örneklerde OCR kök eşleşmesini, ipucunun yanıtı ele verip vermediğini, Türkçe pedagojiyi, gecikmeyi ve gerçek tüketimi karşılaştırın. Ders sağlayıcısını ayrıca karşılaştırmak için `--operations lesson` kullanılır.

```sh
python -m scripts.evaluate_models --allow-paid --candidate gpt-6-luna --operations vision interaction
```

Önerilen sonraki iş, 14 Ocak’tan önce yetkilendirilmiş bir değerlendirmede bu iki yolu sınamak, öğretmen incelemesiyle aday kararını kaydetmek ve kabul edilen işlemin model değişkenini kademeli değiştirmektir. Gerçek öğrenci verisi veya üretim projesi bu karşılaştırma için gerekli değildir.

## Kalan sınırlar

- ESLint’in doğrudan kullanılan sürümü 10.15.0. Next ESLint yapılandırmasındaki bazı eklentilerin bildirdiği eş bağımlılık aralığı npm’in ayrıca ESLint 9.39.5 kurmasına yol açıyor. Temiz kurulumda bu dolaylı sürüm için destek sonu uyarısı var. Lint kuralları açık kaldı.
- Next.js, KaTeX, sharp ve ilgili geçişli paketler kayıtlı npm güvenlik bildirimleri nedeniyle hedefli güncellendi. Çalışan Next.js sürümü 16.4.6, KaTeX 0.18.2. Denetim sonucu yalnız kullanılan npm kayıtlarının kapsamını gösterir.
- GitHub Actions iş akışı PR ve main push olayları için tanımlı ve yalnız `contents: read` ister. Yerel dal gönderilmediği için bu değişikliklerin GitHub üzerinde çalışan bir CI sonucu yoktur.
- Docker ve WSL ortamı bu makinede hazır değildi. Linux çekirdeğindeki CPU/adres alanı limitleri, Docker imajı, gerçek Cloud Run revizyonu, gerçek cihaz tarayıcısı ve üretim IAM/indeksleri canlı olarak doğrulanmadı. Süre sınırı ve işçi süreci Windows üzerinde sınandı.
- Yerel geliştirmede web için Firebase değişkenleri süreç ortamında veya `apps/web/.env.local` içinde, API ayarları kök ortamında verilir. Yerelde ücretli işlem için yetkilendirilmiş bir geliştirme hesabı gerekir. Firebase Console adımlarının tamamlandığı varsayılmamalıdır.
- AI kalitesi, öğretmen onayı, tüm matematik konuları ve küresel harcama tavanı bu sonuçlarla doğrulanamaz. Mevcut doğrulayıcı sınırlı ifadeler için çalışır. Yeni Firestore kayıtlarının saklama politikası kurumun veri yönetişimine bağlıdır; otomatik toplu silme veya eski veri göçü eklenmedi.
